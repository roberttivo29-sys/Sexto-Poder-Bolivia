# Sexto Poder Bolivia 🇧🇴

Portal de noticias independiente - Periodismo sin filtros.

## Características
- Panel de administración completo
- Sistema de noticias con flags (Hero, Ticker, Popular, Semana, Recomendada)
- Diseño responsive y optimizado
- Carga de imágenes y videos
- Buscador en archivo histórico

## Tecnologías
- Python 3.10+
- Flask
- SQLite
- HTML/CSS/JavaScript
